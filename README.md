**Drinking-Time-Now**

*Drinking Time Now is a Qt-based desktop application that reminds you to drink water regularly. Stay hydrated and healthy!*

Drinking Time Now 是一款基于 Qt 的桌面提醒工具，帮助你定时喝水，保持身体健康！

**Features / 功能**

- Customizable reminder intervals / 可自定义喝水提醒间隔
- System tray support / 支持系统托盘运行
- Desktop notifications / 原生桌面通知提醒
- Daily intake tracking / 每日饮水量统计
- Cross-platform support (Windows / macOS / Linux) / 跨平台支持

**Usage / 使用方法**

1. Launch the application. / 启动应用。
2. Set your reminder interval in the settings panel. / 在设置面板中设定提醒间隔。
3. Keep the app running in the system tray. / 让应用在系统托盘持续运行。
4. You will receive a desktop notification when it's time to drink. / 每次到点时会收到桌面通知。

**Tech Stack / 技术栈**

- Qt (C++ / PyQt5)
- SQLite for storing daily records / 使用 SQLite 存储每日喝水记录
